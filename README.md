## Deskripsi

Project game sederhana yang dibuat menggunakan Unity dan C#.
Project ini dibuat untuk menerapkan konsep Object-Oriented Programming (OOP), State Machine, Delegate, dan Events.

## Implementasi

### GameManager

GameManager digunakan untuk mengatur sistem utama game, seperti sistem pengumpulan koin dan kondisi kemenangan.

### PlayerMovement

PlayerMovement digunakan untuk mengatur pergerakan player menggunakan Unity Input System.

### OOP

#### Inheritance

Class `Zombie` merupakan turunan dari class `Enemy`.
